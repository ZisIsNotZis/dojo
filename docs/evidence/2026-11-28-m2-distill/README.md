# M2 提炼清单：认可快照、原话与分类提议

2026-11-28，公开基线 `c1b435a`。本轮要回答的问题是：正常谈完并认可后，打开清单能不能分清**可试做法、经验陈述、待确认问题、未认可草稿**，看到每种判断缺什么依据、与原卡是什么关系、来自哪段原话。

**结论**：这条离线切片走通了。`discuss → pipeline --classify → distill --text` 都从真实 CLI 入口运行；三版认可分别列为做法、经验、问题，EOF 留下的一版单列为未认可草稿。后来编辑同 ID 的 v4 不替换历史认可；错误场次不发送材料；伪造引文不写分类；单会话卡不进广播；重开清单不改库。

**边界**：模型是回环上的合成桩。证明的是入口、绑定、发送范围和可读输出，不是分类质量。本进程没有获准模型线路，因此**没有真实模型判定，也没有用户看过这场清单**，M2 的人工检查点仍未关闭。

## 用户看到什么

样例 [`reader-sample.txt`](reader-sample.txt) 保留模型桩条件下的完整输出，只有轨迹目录规范成 `$OUT`。每个认可版本先有一行结论，再依次列范围、前提、替代解释、认可时留下的未知；随后是分类理由、尚缺依据和逐字原话，并指出原话轮次、认可轮次和轨迹路径。近邻关系明确标作提议，旧卡范围直接放在对照处。

这比旧入口多回答了三件事：**这一版当时认可的边界是什么**、**哪些话是用户说的、哪些只是模型判断**、**判断缺什么**。旧入口的同卡三个历史认可会消失，只剩当前（后来改写的）版本；如果用户在同一秒完成 A→B→A，第三次认可还会错指第一次的原话。

## 复核步骤

依赖 Python 3.10+，不需要授权线路或网络出口。脚本只监听 `127.0.0.1` 的临时端口，使用新库，不读取你的默认库。

```sh
cd <干净检出>
umask 077
OUT="$(mktemp -d)/m2"
python3 -B docs/evidence/2026-11-28-m2-distill/verify_distill_cli.py . "$OUT"
python3 -B docs/evidence/2026-11-28-m2-distill/verify_distill_reapproval.py . "$OUT/reapproval"
```

第一条打印 `PASS real CLI: 3 exact approvals, 1 separate EOF draft, rejected bad quotes, no broadcast, no mutable drift or rerun side effect.`。第二条专门重演同一秒 A→B→A，确认 v3 绑定第三次认可的原话；它最多重试五次以碰到同秒。产物在 `$OUT`，包括真实讨论屏幕、轨迹、分类请求、清单 JSON、人读清单和错误分支读数；可以删掉，不影响库。

不带模型线路也能看离线清单与未判定状态。想走真实判类，必须另行配置已获准的 `DOJO_LLM_BASE_URL`、`DOJO_LLM_MODEL`（以及需要时的密钥存储），然后显式运行：

```sh
python3 -m dojo --db "$DB" pipeline --session "$SESSION" --classify --trace "$TRACE"
```

这条命令会把本场待处理认可快照和到认可轮为止的用户原话片段发给该线路。不想上传原话就不要加 `--classify`；清单仍能读，类型会注明未判定。

## 反例与证据

| 要防的事 | 怎么验 | 结果 |
|---|---|---|
| 后来编辑同 ID 卡，旧清单跟着换成新措辞 | 认可 v1–v3 后先 `revise` 成 v4，再开清单 | v4 不出现；v1–v3 的字段与认可时逐字一致 |
| 只有 `--session` 标签或来源形状，被当成认可 | 手工写入带 session/来源的卡，开清单 | 标「没有本场认可记录」，不分类 |
| 认可事件存在但快照丢失 | 删掉 v1 快照，保留认可事件 | 报不可绑定事件；不以当前同文卡冒充 |
| 错误场次或伪造引文 | 换 `session_end` 场次；模型引用没说过的话 | 前者零请求；后者整体拒收，不写部分分类 |
| 同一秒 A→B→A，v3 错指 v1 的原话 | 真实 CLI 三次认可；检查分类包 | 修复前 v3 指向第 2 轮；修复后指向第 6 轮 |
| 打开清单产生写入或再次调用模型 | 比较前后 SQLite SHA-256 与事件账本 | 字节不变、零新事件、零请求 |
| 单会话结论进入跨场广播 | 用清单里的问题查询广播 | 实际命中但拒收，理由 `single-session` |

更细的脚本断言在 `verify_distill_cli.py` 与 `verify_distill_reapproval.py`；确定性回归在 `tests/test_m2_distillation.py` 和 `tests/test_pipeline.py`。两份脚本由独立复核者编写，集成人在候选树上复跑后收入。全量 `python3 -m unittest discover -s tests -q`：1403 项通过。

## 仍不能声称什么

- 逐字引文只证明它出现在提供的本场轨迹里，不证明它切题、能推出该类型或为真。
- 模型可能把「想试」误判成已有效果；这类判断是待你修正的提议，不是已核验知识。
- 超过单批上限的长会话需要再次显式运行；`deferred` 会计数，不会静默丢掉或假装整场已判完。
- 轨迹是本地文件：版本字段绑定的是本程序写下的认可记录，不是对整份证词的签名或防篡改证明。
- 本轮没有真实模型分类质量证据，也没有跨场广播改变讨论质量的证据（M3 不在本轮）。
