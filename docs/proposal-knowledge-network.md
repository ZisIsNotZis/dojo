# 提案：把道场做成一个「道」的数据库

## 一句话
我提议把道场的中心从「一次对话的体验」换成「一条道的生命」：一条道不是一张卡、也不是一句引文，而是一个带情境、张力、动作、代价、失效条件与归属的函数；产品做三件事——从一个人的具体经历里把它拔出来、把它和已有的道对齐、再把它组织好还给这个人；证据不靠"能不能核实"，靠"网络自己先写下预测、再拿观察对照"的对抗台，且人不是检查者；独立性按人与情境的双重来源算，缺记录一律算不独立；规模上只收敛骨架（张力与情境类），让案例发散。
这个改动会替换掉现在的数据模型（卡 + 词面检索 + pass 提议），而不是在它上面加字段；M2 的收尾照原样跑完，M3 之后的重心换到这里。

## 规模还没被挣得（2026-10-23 的读数）

到 2026-10-23 为止，这个库只有**一个真人**的具体经历：三条道、一张道图与一页对比，全部来自同一个人。
所以它现在能证明的是「一条道能被完整地生出来、被网络自己检一次、并把没跑过的那格印出来」，不能证明「不同人的道会收敛到同一批张力上」。
目标不变，仍是第六节与第七节写的「人类的道」；要走到那一步，第一个需要的东西是一个真实第二人的一场会话——`docs/probe/tension-convergence.md` 是那场会话的仪器，它现在零笔记。
在那之前，任何一处把这个库写成「人类的道」，都是把目标当成了读数。

## 状态（2026-10-23，person 已答）
三件事他都答了，方向照提案走，只有一条改动把设计改掉了：
- **单位**：卡 → 道。旧卡只映射，不迁移、不删。
- **证据**：要，但**不是**由人确认。person 的原话是"不是用户确认，用户已经抽身了，提醒那不是他的责任，是你下面那张网络的责任；他以后可以质疑，比如问'你跑过模拟吗'，但他不负责提醒"。所以检验层改成**网络自己跑的对抗台**（第二节已按此重写）。
- **首里程碑**：一条道的一生，验收行照第七节。
- 两条默认照旧生效：独立性收紧到"曝光未知 = 不独立"；旧库不迁移、不删。
这份文档因此从"提案"变成"已同意的方向 + 未实现的设计"；实现从第七节那个里程碑开始，本会话不动手。

## 先说清楚现在哪里不够
现在的东西不是错的，是**单位选错了**。
一张卡的身份是它的措辞，所以"两条是不是同一条"只能靠字面重合来判断，而同一件事在不同人嘴里几乎不会用同一句话。
这带来三个连锁后果：检索只能找回措辞像的，合并只能靠人读完再判断，而"这条值不值得信"没有地方可放，因为卡里没有代价、没有边界、没有"谁在什么处境下说的"。
这三件事都不是调参能修的，因为它们共用同一个前提：**一条道的身份在它的字里**。
我的提议是把这个前提换掉：一条道的身份在它的**适用域与动作**里，字只是它的一个投影。

## 一、一条「道」是什么
一条道是六件东西，缺一件就不是道，是意见：
| 件 | 它回答什么 | 坏的写法 | 好的写法 |
|---|---|---|---|
| 情境 | 什么样的人、在什么阶段、受什么约束时，这件事会重演 | 「日常生活中」 | 「一个人要靠重复行为维持一个状态，且动机不足以单独支撑时」 |
| 张力 | 哪两个好东西不能同时拿满，或者哪个东西推到极端会反噬 | 「要注意平衡」 | 「省力与练习：降低摩擦让人更容易开始，也把'在困难里坚持'那部分能力从流程里拿走了」 |
| 动作 | 往哪个方向调、调多少、调在哪一处 | 「要自律」 | 「把摩擦降在'开始'这一侧（归位路径、工具就手），不要降核心动作本身的难度」 |
| 代价 | 谁付、付什么、什么时候显形 | 不写 | 「一次性重设环境；可能失去困难中的练习；别人可能找不到东西」 |
| 失效 | 观察到什么就该停、什么情况下反过来 | 「因人而异」 | 「当目标本身就是训练，或摩擦本身是安全检查/学习步骤时，这条反过来」 |
| 归属 | 谁在哪个处境里说的、是亲历还是推得 | 「网友」 | 「甲，2026-10，一手经验；乙在另一个领域独立得出相容版本」 |
一条道写成一句给人读的话，长这样：**「在 S 里，宁可 A 不 B，代价是 C；当出现 D 时，反过来。」** 这句话的形状里已经藏了全部判据：S 是适用域，A/B 是张力，C 是价格，D 是失效条件。
主张只有真假，引文只有作者；道有适用域和价格，没有作者，只有出处。
这就是它和"一条 claim"、"一句 quote" 的区别。
落到存储上，一条道是这样一张记录（示意，不是已实现的 schema）：
```yaml
id: dao-0142
version: 3
situation:            # 情境类：能被没听过这个人的人认出来
  who: 靠重复行为维持一个状态的人
  when: 动机不足以单独支撑时
  constraints: [环境由自己控制]
tension:              # 张力：两个好东西不能同时拿满
  name: 省力 vs 练习
  sides: [更容易开始, 在困难里坚持的能力]
move:                 # 动作：方向 + 幅度 + 作用点
  direction: 降低摩擦
  locus: 开始这一侧，不是核心动作本身
price:                # 代价：必须写，谁付、付什么单位、何时显形
  - 一次性重设环境（时间）
  - 失去困难中的练习（能力）
  - 别人可能找不到东西（关系）
off:                  # 失效：观察得到的停止/反转条件
  - 目标本身就是训练（体能、专注、手艺）
  - 摩擦本身是安全检查或学习步骤
domain: [日常重复行为, 工具与流程]
provenance:
  - person: p-8f2a          # 稳定匿名 ID，不是 session
    session: s-5d1e         # 哪一场（可追溯到轨迹，但不进独立性计算）
    episode: ep-0031        # 具体事件，不是概括
    status: 自述
    learned_from: 亲历     # 同源判断用
  - person: p-1c77
    episode: ep-0088
    status: 自述
    learned_from: 独立     # 用自己的处境得出，没读过前一条
    exposure: none-at-time  # 曝光账本：写这条时未见过 p-8f2a
checks:                 # 对抗台的三个回执；只追不改，缺一格就印"未跑"
  - kind: coherence    # 自洽：结构
    ran: {by: pass/structure-v1, at: 2026-10-24T09:12Z, on_version: 3}
    verdict: pass
  - kind: falsifiable  # 可反驳：两个处境，两个动作
    ran: {by: pass/simulate-v1, at: 2026-10-24T09:14Z, on_version: 3}
    cases: [{inside: 归位路径缩短到一步, action: 先做归位},
            {outside: 目标是练手艺, action: 先做完整练习}]
    verdict: pass
  - kind: field        # 落地：世界里的一条观察
    ran: null           # 未跑；印给人时就是这一格
    observation: null
relations:
  - {kind: contradicts, to: dao-0201, on: 同样情境下方向相反}
  - {kind: variant, to: dao-0117, on: 代价不同（关系 vs 时间）}
```
这张记录里有两处是现在的卡没有、也加不上的：`provenance` 里的人是稳定 ID 而不是会话，`checks` 里的回执带"谁跑的、对哪个版本、跑出什么"。
前者决定独立性算不算得出来，后者决定状态能不能升——以及"没跑过"能不能被看见。
两者都不是字段问题，是这张记录在系统里怎么被读写的问题。
**两条什么时候是同一条**，不用相似度，用一次替换试验：把两条道分别放进同一个情境，按它做的人会不会做出不同的动作？
- 动作相同、领域相同、代价同类 → **同一条**，合并，保留两份出处。
- 张力与方向相同，但领域不同或代价不同 → **同一条道的两条条件路线**（一个节点，多条 route），不合并成一句更抽象的话，也不拆成两条互不相干的道。
- 领域重叠、方向相反 → **两条**，连一条「相反」边，两条都留。分歧本身是数据：它说明价格或情境还没说清。
- 张力不同 → **两条**，不连。
这条试验的好处是它能被一个人在一次阅读里判完，也能被模型提议、由人确认——沿用现在"合并只提议、不自动执行"的规则，只是判据从字面换成了动作。

## 二、真从哪来（当没有人能核实的时候）
互联网的病根是**断言与证据是同一个对象**：一段文字既是"有人说"，也是"根据"。
所以任何"我在网上查到了"都不解决问题，它只是把断言换了个作者。
这里的做法是物理上把三层分开，三层不共用一张表：
1. **事件层**：一个人在某天说"我做了 X，看到 Y"。带日期、处境、结果，不带概括。
   它是**报告**，永远不被当成"这条道成立"的证据；它证明的是"这个人这样经历/相信"。
2. **提炼层**：从一条或多条事件里拔出来的道，带着"从哪几条事件拔出来的"这条边。
   它可以被重新推导，所以它不是凭空的。
3. **检验层**：这条道对未来做出的**可观察预测**，以及后来实际发生了什么——而写下预测、去核实它、发现它没被核实的，都是**网络自己**。

**2026-10-23 的修正（person 的原话）**："it's not user confirm, user is already detached, he's not responsible for challenging, your underlying network is. He CAN challenge later, e.g. 'did you do simulation?', but not responsible for reminding that."
这句话否掉了提案第一版里的一个设计错误：我原来把检验写成"下次见面问一句『后来呢』"，那等于把记账的活交回给人。
那正是我们自己的 P2（要求用户维护结构化工件就会失败）换了一件衣服。
所以检验层不是一个人工确认回路，而是网络对自己条目的一场**对抗**。

### 对抗台：网络自己跑的三道检查
每一条道进库或升版时，都排进对抗台，由网络产出三张**回执**，每张回执写清：检查名、跑的是什么、对哪个版本、谁跑的（哪个 pass、哪个模型、哪个确定性脚本）、何时、结论（过／不过／不确定），以及（若有）它引用的那条观察。
回执是只追不改的：版本一动，旧回执留在旧版本上，新版本要重新拿到自己的回执。
1. **自洽**（结构，确定性为主）：六件套彼此咬合——动作是否作用在它自己命名的张力上；代价是否落在动作真正花掉的那种资源上（时间、关系、机会、能力）；失效条件是否**真的与动作相反**，而不是一句"因人而异"；情境类是否覆盖它的案例。
   抽掉一句套话就通不过的条目，过不了这一关。
2. **可反驳**（模拟）：网络从这条道自己生成两个处境——一个在适用域内、一个刚好越过失效条件——然后问这条道：在这两个处境里，它会让你做出**不同**的动作吗？
   两个处境给出同一个动作，说明失效条件是装饰，结论是"不过"。
这就是"did you do simulation?"的回答：跑过，回执里有两个处境、两个推出的动作、和一个结论；没跑过，回执栏就是空的。
3. **落地**（观察）：世界上有没有一条与它相关的观察。
   三个可接受的来源，强度从低到高：**他人的后续会话里自然出现的结果**（不是被追问出来的，而是同一情境类再次被谈到时自己说到的）、**agent 在自己的真实任务里应用它并记下结果**（标"自验（agent）"，真实但弱）、**有意的对照**（标"量过"，最贵，近期基本没有）。
没有来源，落地这一栏就是"未跑"，不拿"说过很多次"顶替。
三道检查的分工，正好对上第 1 节里"六件套缺一件就不是道"那句话：自洽防的是**拼凑**，可反驳防的是**不可证伪**，落地防的是**只有人说过**。

### 一条道在人面前长什么样
状态不再是一个形容词，而是从回执算出来的三格：**自洽过没有 / 可反驳过没有 / 落地有没有观察**。
一条没人跑过检查的道，在任何面向人的地方都必须原样印出它的空：`自述 · 未检（0/3）`，并以"某人说……"的句式出现，不得写成建议。
这不是文案要求，是接口要求：任何渲染一条道的出口（返还、广播、导出）都带 `check_ledger`，缺少回执就印"未检"，把"未检"渲染成"已验证"的代码路径应当测试失败。
理由还是隔离守卫那一课：**缺席不能当通过**——这一次缺席的是回执，不是来源组。

### person 的位置：一个权利，不是一个机制
他随时可以问一句"这条跑过没有，是模拟还是真的？"，答案是一次读回执，不是一段解释；如果没跑过，系统必须当场说没跑过，并把它降回它挣到的状态。
这是他的**权利**，系统不靠它运转：他忘了问，条目照样有回执或照样印着未检；他一年不回来，库也照样知道自己哪一条没被检验过。"提醒系统去检验"永远不是他的活。
状态仍用五个词，但现在每个词都指向一张回执：
- **传闻**：听别人说的。只进案例，不进道。
- **自述**（reported）：本人亲历，且这份亲历是一段可指认的事件。这是多数道的起点。
- **推得**（inferred）：从别的道推出来的，没有案例。标出来，因为它是模型最像人话、也最容易错的部分。
- **验过**：落地那一格有一份观察，且观察不是写下这条道的人在同一时刻的自述（agent 自验单独标，弱一档）。
- **量过**（measured）：有反事实——不做会怎样，或 A/B、前后对照。个人道理里这极贵，近期基本不会有；**没有就写没有**。
- **合写**（co-written，2026-10-23 加）：六件里有一些是系统补的，不是他说的。它不是比「自述」低一档的证据，它是另一根轴：作者与证据分开。**只要有一件是系统补，这条道就不能叫自述、验过或量过**——那三个词都在说「这是他的话」，而它有一半不是。条目的等级被最弱的那一件封顶；读者读它时只能得出「他这样做的假设」，不能得出「他的看法」。
反例不是降级，是**改适用域**：在案的失败把情境收窄，状态随之打回自述或推得，旧版本不删。

**一条推断件怎么变成他的。** 情境、张力、代价、失效中凡是标了「系统补」的，只有一个出口：他后来自己说了一句话，那句话逐字落进事件层，要么确认、要么推翻它，并带回执（谁跑的、对哪个版本、跑出什么）。确认的，那一件改成他的（原话或转述），条目的作者跟着变；推翻的，按反例处理：改适用域、升版本。**确认不等于晋升**——确认只说明他写过那两头，不说明他把「两者不能同时拿满」这句话说出来过；取舍要他亲口说，才算他的。

### 一条只有规则的还算道吗（2026-10-23 的决定与价格）

事实：13 条里 11 条的动作是他的、张力是我的（情境与代价 13/13 也是我的）。两条路，选了 A：

- **A 一个单位 + 合写 + 晋升**（选了）。道仍是六件，但每件带作者；缺的那几件标「系统补」，条目降为「合写」，并且有一条明确的晋升路径。
  **价**：每条道在晋升前都是假设，而晋升依赖他回来一次——他不回来，库就永远停在合写；好处是它不下断言、不丢信息，也不会把「我补的张力」冒充成「他的道理」。
- **B 两个类**：他说他做什么（规则）与实际被后来的话挣得的道，分开存、分开数。
  **价**：假完整立刻被拆掉（这是好处），代价是产品的话要改（「你的道图」变成「你的做法 + 你的道」），库的大部分长期停在「他的规则」而不是「道」；而 B 也逃不掉晋升——规则要变成道，仍然要一句取舍。所以 B 不是另一条路，是 A 在晋升率长期为 0 时的退化形状。

**能推翻这个选择的观察**：如果接下来三场（或一次会话里他给了 ≥1 句取舍）而我们一次都没晋升成功，说明晋升路径在等人这件事上不成立，就按 B 拆成两类；如果三场之后晋升仍是 0 且他不打算再回来，库的名字就该从「道」改成「他的规则」。现在：晋升 0 条，13 条全是合写。
这套东西不回答"它是不是真理"，它回答三个能被观察的问题：它自己咬不咬合；它在边界两侧是否给出不同动作；有没有一条真实观察与它相符或相悖。
三个都可数，前两个网络自己就能跑完，第三个不跑就印"未跑"。

## 三、出处与独立性：隔离守卫那次漏判会换个形状回来
我们自己的隔离守卫已经踩过一次：一张卡没有任何独立性组时，代码把空集读成"不是单一会话"，于是放行。
修法是三条——来源 = 来源组 ∪ 写过它的会话、缺来源判 `unidentified`、空集不再等于通过。
这三条在这个新库里会以另一种形状重演，而且更容易骗过人：
- 同一个人的第二场会话说"对"，看起来是两个来源，其实是一个人的回声。**所以来源组是"人"，不是"会话"**：同一个人无论来多少次，只算一组。
- 第二个人在读到第一个人之后说"对"，看起来是独立同意，其实是传播。**所以要有曝光账本**：一条道每次被展示给谁、在哪个版本、什么时间，都记一行（系统自己在展示时记，不向人索取任何东西）；被曝光过的人的同意记为**共鸣**，独立权重为零，但它是另一种有用的信号——它说明这条道容易被接受，而"容易被接受"和"独立成立"是两件事，分开记。
- 两个人各自独立说"对"，但都说是同一个师父/同一本书教的。人不同，来源不独立。**所以来源要能记"我从哪学的"**，同源记一组。
- 缺记录的时候，**一律按"不独立"算**，不按"可能独立"算。这是那次评审判 fail 之后唯一值得原样搬过来的那句话（缺陷编号 D1 / C2）：**缺席不能当通过**。
判定就变成一句可机械检查的话：这条道的独立来源数 = 不同的人 × 不同的情境出处（领域或约束不同）× 没有同源传递 × 有各自的案例，四项都满足才算一组。
第二个人只说了"我同意"而没有自己的案例，不算一组——同意一个命题是廉价的，说出自己在什么处境里怎么做才不廉价。
这套口径会让数字变小，小得难看：一场会话的产物大概率是"一组"，不是"三组"。
这是对的。
宁可一开始就看见"这个库现在其实只有一个人的道理"，也不要三年后才发现所有"共识"都是同一个人的回声。

## 四、你拿回什么（产品的组织动作）
现在的产品给你一场好对话；提议后的产品把**你自己**整理好还给你。
会话结束返还四样东西，全部用你的原话做锚，不用系统的话覆盖你：
1. **你的道图**：你这次说的东西被收成 3–7 条道，每条六件套齐全，每条下面挂着你当时说的原话（原话是证据行，不是装饰）。
2. **你的矛盾**：你前后不一致的地方——两条道在同一个情境给出相反动作。
   系统不裁决，只摆出来问你一句。
这是整份返还里最不舒服、也最值钱的一页。
3. **你的空白**：你反复踩、但没有解法的那些张力，以及别人在同一张力上的道（转述、带条件和代价，不带"你应该"）。
4. **一句能带走的**：一句你自己会说的话，后面跟着"什么时候别用"。
   **一次返还长什么样**（示意，用现有 demo 的三位角色材料构造，不是用户研究）：一个人先讲房间乱（归位太麻烦），再讲写代码（总先写代码再想需求），再讲健身（坚持不了）。
系统把三件事收成同一条道——「把正确行为的摩擦降下来」——然后停住：健身那条给出反例，因为那里的难度本身就是收益。
于是你的道从一句口号变成一条带边界的道，加一条反例，加一个价格（你少练了那部分能力）。
你得到的不是"三条建议"，是"我一直在说同一件事，而且我一直漏掉了它的价格"。
**这就是那个组织动作**：不是把话变短，是把散落的经历收成一张有边界、有价格、能推翻的地图。
判断它有没有做成，不看你说"有用"，看两件可观察的事：你能不能一句话确认一处你自己没意识到的连接或矛盾（"对，这两件事是一回事"或"不对，因为……"）；以及你下次来的时候，会不会带一个反例或一个新处境。
第一件当场可看，第二件要等下一次——所以它得是里程碑的验收，不是发布会上的话术。

## 五、人为什么来，而不是被抽取
**我要向一个人要什么，说白**：三十到四十分钟，讲一件他做过很多次但从没写下来的事；允许被追问"什么时候不成立"；允许我们把提炼结果摆给他看，并且他可以一句话推翻。
不要他填表、不要他学概念、不要他维护任何东西——**也不要他记得回来告诉我们哪条应验了**。
**他付的代价**：时间；说真话（包括自己做错的部分）；看自己矛盾的那一页会不舒服；以及被提炼错的风险——所以我们给他一次推翻的机会，且写入可撤销。
**他不付的代价**：质疑的责任。
检验由网络自己跑（第二节的对抗台），他不需要记住任何一条待检验的道，也不需要回来给任何东西盖章；他只在想推翻的时候出手，那是权利，不是任务。
**他拿到的东西**，按强度排：立刻能用的返还（他自己思想的整理，不需要他相信任何东西）；被认真对待（AI 追问边界而不是附和，这在今天很稀缺）；**一件他从没要求过的东西——他的道被网络自己在检验，而他知道哪一条还没被检验**；匿名的影响（他的道会以"另一个陌生人在不同处境下……"的形式出现，不署名、不排行）；以及一张随时间变厚的自己的地图，可导出、可删除。
### 我要问的四句话（2026-10-23 定稿）

他说的是动作；另外四件得从他嘴里出来，否则那一件就是系统补、条目就是 `合写`。四句问法（每句都写成「不用教他模型就能答」的样子，这四句问法的失败形态、两种追问答法与「一句回答要有什么才算数」，只有一份，在 `dojo/elicit.py`）：

1. **情境**：「什么时候你会这么做、什么时候不会？先说上一次：那天你手上是什么事，卡在哪一步？」
2. **张力**：「照着这条做，哪件本来也挺好的事会变得差一点？」
3. **代价**：「这件事落下去，谁要多花时间、谁会不高兴？第一次觉得亏，是什么时候？」
4. **失效**：「有没有一次你这么做，结果反而不对？那次和平时差在哪？」

一次只问一件；每件最多两轮（一问 + 一次换问法），两轮没有就停——那一件留系统补、条目留 `合写`，**不问第三遍，也不替他填**。
这四句已经接进讨论本身（`dojo/discuss.py`）：一条结论在他说「对」的那一轮写进去之后，主持人接着按这四句问；他没有答的那几件停在系统补。

**代价是量出来的**：拿他自己过去的话当答案演练一场（`docs/dao/elicitation/run-1.md`），4 条道问了 14 件、填上 4 件，共 24 轮、平均每条道 6 轮；问不出来的 10 件原地不动，四条道全都还是合写。也就是说，一条道要变成他的，大约要多花三到四轮的问与答；而库里现在 13 条是 0 轮长出来的——它们不是免费的，是没付钱。

**他为什么回来**：因为每次返还都给他一件他原来没有的东西（一个连接、一处矛盾、一条边界），而且这张图只在带来新处境时才变厚。
这句话是邀请，不是机制——他不来，库也照样运转，只是他的那一页不长了。
**明确拒绝的**：积分、徽章、排行榜、关注、打卡、付费解锁；也拒绝把"你的数据会用来训练模型"写成默认条款。
这些都能短期拉高采集量，代价是把"人在讲自己的道理"变成"人在生产数据"，而后者一旦发生，这个库就变成第二个互联网。

## 六、规模：哪里断，什么不长大
**要被换掉的朴素设计**：每条结论一张卡，靠词面重合找邻居，靠 pass 提议合并，靠人读完全部来判断重复。
它在几百条时能活，因为一个人读得完；它不可修补，因为它缺的不是检索质量，是**身份**——没有情境、张力、代价、边界这四个字段，任何相似度都只能猜"这两句像不像"，而"像"不是"同一条"。
加字段也救不了：加了这四个字段，节点就不再是卡，那是一次换模型，不是一次打补丁。
三个断点，各自的断法不同：
- **一万条**：断在**人读不完**。一天两百条新增，一周一千四，一个人一天读一百条要读两周，而审阅者（人或一个独立的进程）仍是合并的最终判据。治法不是更快的模型，是**索引**：以"张力"和"情境类"为键，同键的才需要人看一眼；再抽 1% 做审计，看自动提议的错判率。这一层现在就该建，成本很低。
- **一百万条**：断在**命名漂移**。同一件事会被叫成几十个张力名，"张力词典"自己长成一万条，合并变成词表对齐问题。治法是把词典当成从数据里长出来的受控词表（先几百个，人工冻结，新增要理由），不是先验设计一套本体；同时把"谁说的"从内容里拆成边（provenance 边），否则每改一次内容就要重算全部来源。模型判同的成本也要算：每条新道只碰它最像的 20 个邻居，其中只有前 5 个真的调模型判，判过的对缓存到版本；这样每条道的成本是常数，不随库增长。
- **"全部"（十亿人级）**：断在**采集本身**，而且答案是不该全采。真正会收敛的是骨架：人类能共享的张力数量大概率在几千到几万这个量级（这是个假设，见下），而案例是发散的，可以到十亿。所以最大规模的形状不是"一个巨大的图"，是**小骨架 + 巨大边缘 + 可计算的聚合**：每条张力下有一张分歧图谱（谁在什么处境下怎么做、代价是什么），而不是一条"最佳实践"。存储也照这个分：道在带受控词表的关系/图库里，案例是只追加的事件流、按人分片，检索顺序是张力 → 情境 → 代价。
**我会拒绝让它长的东西**：单一本体（Cyc 的路）；全图实时一致（只保证一条道与它邻居的局部一致）；自动合并（只提议）；"真值"评分（把适用域和代价压成一个数，等于把这张库变回排行榜）；公开的人物页（一旦有"谁贡献了多少道"，采集就变质）；跨语言的自动对齐（中文的"道"没有对应词，先做中文，跨语言是另一个产品）；把道做成提示词库（那是另一种东西，会把这个库变成工具市场）。
**这个设计自己背着一个信仰**：人类的道理能收敛到几千个张力。
如果这条是假的，核心会膨胀成引文库，产品就退化成"金句数据库"。
它有一个很便宜的验法，见最后一节。

## 七、如果只能用一个里程碑证明自己
**一条道的一生。** 一个真人（先是他自己，或一个志愿者）用三十多分钟讲两三件具体事；系统提炼出一到三条六件套齐全的道；网络自己把其中一条送进对抗台，跑出三张回执（自洽、可反驳、落地或"未跑"）；返还一张道图，里面至少有一处他自己没意识到的连接或一处边界修正；全程落盘：案例、道、回执、曝光记录。
命令一条，产物是一份人能读的 markdown 加一个道库快照。
验收行，每条都可观察：
- **A1 六件套**：抽三条，每条六项非空；由独立评审读，判"能不能据此在新处境里决定什么时候停"，不是判文采。
- **A2 组织性**：返还里至少一处连接或矛盾是他自己没意识到的，且他能用一句话确认或推翻。推翻也算——它证明系统说的话值得被推翻。
- **A3 对抗台回执**：至少一条道带三格回执，其中自洽与可反驳由网络跑出（回执里能看到两个处境、两个推出的动作、和一个结论）；落地这一格要么有一条观察并注明来源，要么原样印"未跑"。全程不问 person 要任何结果。
- **A4 独立性**：伪造一个场景——把 A 的道给 B 看，再问 B；B 的同意必须被判成"曝光后/共鸣"，不能算独立组。缺曝光记录时判"未知"，不判独立。
- **A5 抽身测试**：第一场会话结束后不再联系 person，里程碑仍能产出上述回执与返还；靠"问他后来呢"才成立的东西，在这一条下算失败。
- **A6 不回归**：现有测试全绿；M1/M2 的会话行为不变。
- **A7 预算**：整个里程碑不超过 40 次模型调用（沿用 `docs/plan.md` 的预算），单场不超过 12 次；人时不超过他 40 分钟。
**这个里程碑不做**：不迁移旧卡（只做一层映射，旧库不动）；不做自动合并与删除；不做"真值"评分；不做多人协作、社交、排行；不做跨语言；不做本体设计（张力词只从材料里长，不先验设计；现已 13 个，见第六节）；不做万条级压测（留给下一个里程碑）；不拿会话数据训模型。

**这一整组教的事，按对这份提案的用处排**：
1. **每个系统都在拿维护合同换结构，没有一个死在缺 schema 上**：Cyc 二十余年、XCON 每年重写一半规则、Freebase 被吸收、Delphi 被自己的东家否证——死因是维护，或者证据。
2. **活下来的那几个，都是"存出处、不存真理"**——Wikidata 的设计语句是"不是关于真理，而是关于陈述及其来源"（二手，页面没抓到），这也正是它们的天花板：被引用的主张从不被检验，只被归属。
   我们要在这之上多一层"网络自己跑的回执与对抗"，否则只是把互联网的归属规则搬进库里。
3. **构念效度是所有人都缺的那一级**：一条只在自身措辞里成立的道，没有任何一条线连到可观察物，按 C&M 的标准就不合格。
   我们把"失效条件"和"事后结果"做成必填，就是在补这条线。
4. **提取方法各有各的成本曲线**：CDM 跨专家冗余、单场探针过载；Delphi 制造共识；Pol.is 只聚合票、不提取条件。
   设计问题不是"能不能不付"，是"你愿意付哪一种"。
5. **所以从第一天就要四件东西**：陈述+出处（Wikidata）、失效条件（Toulmin 的 rebuttal 被我们改成必填）、可观察物的那条线（C&M）、以及一个写成数字的维护预算（Cyc 和 XCON 都缺这个）。

## 九、选项与价格（同一把尺）

- **读过什么**：本仓的 `docs/product.md`、`philosophy.md`、`design.md`、`need.md`、`pain.md`、`plan.md`、`dojo/storage.py` 的独立性实现（`independence()` 与 `attach_source()`）、`docs/evidence/m1.5-checkpoint/`。

- **没做的**：没跑用户研究，没做真人访谈，没写代码，没调用模型端点。文里所有"会在某人身上发生"的话都是**推断**，不是观察；所有价格都是估算，不是读数。
- **那个半天探针还是要做，而且换了一个理由**：对抗台检查的是**单独一条道**是否可反驳，它答不了"不同人的道会不会落在同一批张力上"这个问题；库越大越答不了，因为它的合并正是需要被检验的东西，用合并结果去证明张力会收敛是循环论证。
  所以探针仍是外部的一次独立观察：五个陌生人各讲二十分钟，不用模型、人工提炼，看五个人的张力集合重合多少。
  它现在多了一个用处：先让提炼物过一遍对抗台的"自洽／可反驳"两格，只拿**过得了**的条目去比重合——否则比的是噪声，不是张力。
  成本还是半天加零模型调用；结论决定的是这个库的**故事**（"人类的道"还是"一个人的思想整理器"），不是它能不能活——两种结论下第一节到第七节都成立，只是名字要改。
