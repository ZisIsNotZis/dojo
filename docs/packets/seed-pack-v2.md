# 四位可检索 seed 候选 v2：陌生人方法论（模拟材料）

> **数据性质：**这是写好的 POC 模拟语料，不是观察到的用户研究、已验证实践或真实证据。它服务于 [current-demo-direction.md](../current-demo-direction.md) 的三位陌生人故事：甲（空间整洁）提出的抽象道、乙（软件开发）的应用路线、丙（抽象挑战）的边界。来源 ID 与 `dojo/storage.py` 中 `SEEDS` 一一对应。旧版是基于虚构 Forge 格式迁移的 `seed-pack-v1.md`，保留为历史材料，不再是当前 demo 的 seed。

## 主题

“一件想要的行为怎样才能持续发生。”具体应用出现于物品归位整理与软件需求澄清两个互不相关的问题中；抽象道只保留可迁移的理由、条件与未知，不包含某个人的私人场景。

## M01 — 抽象道：环境设计比临时决心更稳

- **主张：**环境与流程的设计，往往比临时的决心更能稳住重复行为；降低启动摩擦通常比反复下决心更可持续。
- **类型/来源：**`abstract_idea` / `abstract_reasoning`（`src-m01`）。
- **前提/边界：**行为会重复发生；意愿与摩擦在讨论上可以分开。若困难来自“不知道怎么做”，降低操作摩擦帮助有限。
- **核验：**`not_evidence`。这是值得讨论的抽象区分，不是效果报告。

## M02 — 条件路线甲：行为无训练价值时减少步骤

- **主张：**若只是想维持现状、且这个行为本身没有训练价值，那么减少步骤、把正确动作的准备前置，通常能提高它持续发生的概率。
- **类型/来源：**`application` / `abstract_reasoning`（`src-m02`）。
- **条件：**行为本身不构成能力练习；减少的只是与目标无关的步骤。
- **关系：**`narrows` → `seed-m01`。
- **核验：**`not_evidence`。

## M03 — 对向条件路线乙：练习价值需要保留难度

- **主张：**若一个行为的价值正来自练习过程本身，那么降低难度等于同时去掉练习机会；这时应保留有意义的难度，只去除与目标无关的无谓摩擦。
- **类型/来源：**`application` / `abstract_reasoning`（`src-m03`）。
- **条件：**能力的形成本身依赖练习过程。
- **关系：**`narrows` → `seed-m01`。
- **核验：**`not_evidence`。与 M02 是不同条件路线，不互相取消。

## M04 — 未核验的经验报告

- **报告主张：**一名模拟角色自述靠每次只做一件小事坚持了数月整洁，而没有依赖更强的自律。
- **类型/来源：**`experience_claim` / `claimed_firsthand`（`src-m04`）。
- **独立性：**仅一个被声称的记忆；`independence_group: unknown`。重复讲述不构成第二个独立来源。
- **缺失材料：**时间范围、是否中途失败、是否换了别的做法、是否有独立来源，均缺失。
- **核验：**`unverified`。保留其主张，但不得作为已证实的成功案例，也不得估算成功率。
