# dao/ — 一条道的一生（K1）

这一层把三层分开放，再用一条命令接起来：具体经历（事件层）、从它拔出来的道（提炼层）、网络自己在道上跑出来的回执（检验层）。
它不是新产品能力，也不是模型提炼；它证明的是：一条道能被完整地生出来、被网络自己检一次、把它没跑过的那一格原样印出来；两个来源能被同一条命令跑、并按受控词表逐对比出来。

这里有两个库：`person-dojo/` 是真人（本仓的使用者，`p-dojo`）的记录；`demo-strangers/` 是记录里唯一另一批具体材料——模拟语料，**不是人**。
第二个库存在的理由只有一个：测这张库装不装得下第二个来源。它不回答「不同人的道会不会收敛」。

## 一条命令

```sh
python3 scripts/dao_life.py docs/dao/person-dojo --compare docs/dao/demo-strangers --at 2026-10-23T14:02:48Z
```

退出码 0 当且仅当每条道的自洽与可反驳都过、每条「落地未跑」的道都写明了要什么。它写五份生成物：两个库各一份 `receipts.json` 与 `道图.md`，外加第一库目录下的 `对比.md`。
`--check` 只判不写。不带 `--at` 时回执里的时间写成 null，其余不变（同一 `--at` 重跑，生成物逐字节相同）。不调模型、不联网、不连数据库。
只看一个库就去掉 `--compare`；词表默认取自数据目录上一层的 `vocabulary.json`，可用 `--vocabulary` 指定。

## 文件是哪一种

| 文件 | 种类 | 谁写 |
|---|---|---|
| `vocabulary.json` | 落盘数据：受控张力词与动作词，八个词，冻结 | 手写；新增一个词要写理由与它从哪条经历来 |
| `comparison.json` | 落盘数据：一次对比的读法与限制 | 手写；没有它，`--compare` 不跑 |
| `<库>/episodes.json` | 落盘数据（事件层） | 手写：原话、路径、行号、来源类别 |
| `<库>/daos.json` | 落盘数据（提炼层） | 手写：六件套 + 张力键 + 动作键 + 一张可判的规则表 |
| `<库>/observations.json` | 落盘数据（落地观察 + `needed`） | 手写：观察与「要什么才能有这一格」 |
| `<库>/exposures.json` | 落盘数据（曝光账本） | 展示时追加 |
| `<库>/map.json` | 落盘数据（连接与边界） | 手写：标 `待确认` |
| `<库>/receipts.json`、`<库>/道图.md` | 生成物 | 命令生成，不要手改 |
| `person-dojo/对比.md` | 生成物 | 同上 |

## 来源分四类，状态词跟着来源走

`person`（他本人的原话）→ `自述`；`relayed`（root 转达）→ `自述（转述）`；`synthetic`（模拟语料）→ `模拟`；`unverified`（署名未核）→ `传闻`，只能当旁证。
一条道的出处里至少要有一条不是 `unverified`。模拟材料可以支撑一个库，但它的状态词永远是 `模拟`，不进独立性，也不进 person 的道图。

## 落地那一格什么时候算数

只认三种来源：他人的后续会话里自然出现的结果、agent 在自己的真实任务里应用并记下结果（自验，弱一档）、有意的对照（量过）。
另外两条是硬的：观察必须晚于案例（案例多为日粒度，所以同一天的观察要写到分）；自验必须写清 `applied_in`（在哪件真实活里用过）、`result`（结果）、`could_have_gone_otherwise`（本来可能怎样），缺一项就不计入，被拒的理由印在道图上。
没有观察的格子写 `未跑`，并且 `observations.json` 的 `needed` 必须写明要什么、为什么现在拿不到、谁能补——不写，命令判不过。

## 对比什么时候可以存在

一次对比必须带 `comparison.json`：命令只算逐对关系（同一张力同向＝变体，同一张力反向＝相反，不同张力＝无关）与词表覆盖；
「读法」和「限制」由人写，两边分开标。对比只读，不改任何一条道——这也是「第二个来源没有改动任何道」这句话能被检查的原因。
