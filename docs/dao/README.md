# dao/ — 一条道的一生（K1 的第一片）

这一层把三层分开放，再用一条命令接起来：一个人的具体经历（事件层）、从它拔出来的道（提炼层）、网络自己在道上跑出来的回执（检验层）。
它不是新产品能力，也不是模型提炼；这一片只证明一件事——一条道能被完整地生出来、被网络自己检一次、并且把它没跑过的那一格原样印出来。

这里的 person 是本仓的使用者（`p-dojo`），材料全部来自仓内已有的记录：他自己的原稿、他说过的话、他被转达的判断。没有新访谈，没有联系他。

## 一条命令

```sh
python3 scripts/dao_life.py docs/dao/person-dojo --at 2026-10-23T13:43:02Z
```

退出码 0 当且仅当每条道的自洽与可反驳都过。它写两个文件：`receipts.json`（回执）与 `道图.md`（给人读的那一页）。不调模型、不联网、不连数据库。
`--check` 只判不写；不带 `--at` 时回执里的时间写成 null，其余不变（同一 `--at` 重跑，两个文件逐字节相同）。

## 文件是哪一种

| 文件 | 种类 | 谁写 |
|---|---|---|
| `person-dojo/episodes.json` | 落盘数据（事件层） | 手写：原话、路径、行号、署名状态 |
| `person-dojo/daos.json` | 落盘数据（提炼层） | 手写：六件套 + 一张可判的规则表 |
| `person-dojo/observations.json` | 落盘数据（落地观察） | 手写：只认三种来源 |
| `person-dojo/exposures.json` | 落盘数据（曝光账本） | 展示时追加；这一包 0 行 |
| `person-dojo/map.json` | 落盘数据（连接与边界） | 手写：标 `待确认` |
| `person-dojo/receipts.json` | 生成物 | 命令生成，不要手改 |
| `person-dojo/道图.md` | 生成物 | 同上 |

## 什么时候这里算没过

- 一条道的出处全是「署名未核」→ 自洽判不过（缺席不能当通过）。
- 一条道的失效条件改到越界、动作却没变 → 可反驳判不过：那是装饰。
- 一条道带套话（「因人而异」之类），或代价的单位不在 `时间/关系/机会/能力` 里 → 自洽判不过。
- 一条道引用了事件层里没有的案例，或引用了 `window.last_person_input` 之后的 person 输入 → 自洽判不过；后者说明那是第二场，本包不拿它补。

## 现在哪里还弱（别把它读成已完成）

- 提炼是这次会话的 agent 读出来的，不是模型判的，也不是 person 确认的；凡读法处标「推断」。
- 落地那一格只有一条弱观察——他自己那一局之后的判断，混杂未排除；另外两条是「未跑」。
- 可反驳这一格证明的是结构：边界一改，动作就变。它不证明「这两个处境在世界上真的不同」——那要读回执的人判，正是提案第九节写下的那条风险观察。
- 独立性只有 1 组：一个人的道理，不是共识。曝光账本 0 行，按「曝光未知 = 不独立」算。
- 边界 `b-001` 没有写进 `product.md` 与 `need.md`；它标 `待确认`，等 person 一句话。
