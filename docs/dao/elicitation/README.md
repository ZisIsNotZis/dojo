# elicitation/ — 问什么，以及问一次要几轮

这个目录放的不是道，是**问**。一条道里他说的是动作；另外四件（情境、张力、代价、失效）得从他嘴里出来，否则就是系统补、条目就是 `合写`。所以产品真正的东西不是库，是他讲一条做法的那一刻，我们问了他什么。

## 文件

| 文件 | 是什么 |
|---|---|
| `questions.json` | 四句问法的家：每件写 `ask`、它会招来什么（`failure_mode`）、他答成另一条做法或答不出时怎么接（`follow_ups`）、一句回答要有什么才算数（`to_fill`）。 |
| `session-1.txt` | 一场模拟会话：被访者的每一句都逐字来自事件层（带 episode 与出处），提问与重问是 harness 的台词。 |
| `run-1.json` / `run-1.md` | 生成物：这场会话的投影。不要手改。 |

## 一条命令

```sh
python3 scripts/dao_elicit.py --library docs/dao/person-dojo --script docs/dao/elicitation/session-1.txt --at 2026-10-23T14:02:48Z
```

`--check` 只判不写。它**不写库**：跑完 `daos.json` 一个字节都不变，投影只回答「如果这些话真被他说出来，哪一件会变成他的」。

## 哪几句是他的，哪几句是 harness 的

- `answer his …` / `answer relayed …`：**他的话**，必须在该 episode 的原话里逐字存在，否则拒收。演练不会变成编造。
- `answer another-rule / story / vague / none`：**他对这一问的回答形态**，逐字同上（`none` 除外）。
- `ask`、重问、以及每条 answer 后面的 `kind`：**harness 的判断**。仪器不判语义——一句回答算不算回答了那一件，是人的判断，写在脚本里、可被复核。

## 现在量出来的是什么（2026-10-23，第一场）

4 条道、问了 14 件，填上 4 件、没填上 10 件，共 **24 轮，平均每条道 6 轮**。四件都问出来的一件也没有——所以这一场之后，四条道**全都还是 `合写`**。

这就是这个产品的真实价格：一条道要把四件都变成他的，得问四件、每件一到两轮；他答不上来的那些，不是「再问一次就好」，而是**停在系统补**。库里现在 13 条是 0 轮长出来的——它们不是免费的，是没付钱。

## 这一场不证明什么

- 他不证明他的答案会是这样：这些话是他过去说的，被拿来当答案，不是被问到才说的。它证明的是「照这四句问，哪一件能落在他真说过的话上」。
- 它不判语义：仪器只保证引文是真的、有人标过它回答了哪一件；标错的活还在人手上。
- 它不改 13 条：投影只是投影。真跑一场之后要改库，走 `promotions.json` 那条路。
