# 道图：三条道（p-dojo）

这几条道说的是同一件事：你要我把「活」拿走，但要先把「样子」和「价」摆在你面前。
其中有一条边界是我读出来的、你没说过；一句话就能推翻它，见「连接与边界」。

**这张图是一个人的。**记录里只有一位真人的具体经历，所以它证明的是这张库能把一个人的经历收成一张带边界的地图，
不证明它装得下第二个人的道理。目标仍是「人类的道」；要走到那儿，需要一个真实第二人的一场会话（`docs/probe/tension-convergence.md`）。

## 这张图里有什么

3 条道，每条六件套齐全；3 条都有自洽与可反驳两张回执，落地那一格 2 条有观察、1 条是「未跑」。
独立来源 1 组（不同的人 1 个；曝光账本 0 行）。曝光未知按「不独立」算：这里是一个人的道理，不是共识。
提炼是这次会话的 manager 从记录里读出来的（凡读法处标「推断」），不是模型判定：这一包 0 次模型调用。

## 一条道长什么样

在 S 里，宁可 A 不 B，代价是 C；当出现 D 时，反过来。S 是适用域，A/B 是张力，C 是价格，D 是失效条件。

## 道三　dojo-d-003　价写在决定旁，决定只问一次

> 在一个人要同意一件花他自己额度的事时，宁把价与上限写在决定旁一行也不先跑起来，代价是每个决定多一行成本说明；当价低于察觉阈值、或花的是系统的机器时间时，反过来。

| 件 | 内容 |
|---|---|
| 情境 | 谁：一个人要同意一件会花掉他自己的额度、钱或时间的事，而这件事由别人（或 agent）去跑；何时：决定一次就能定，但他还不知道这一件要花多少、上限在哪；约束：他愿意花，但要知道单位、数字和上限、同一个动作他不想被问第二遍；领域：决策与成本、与 agent 协作 |
| 张力 | 先问价 vs 先跑起来——两头是「先把价和上限问清再决定」与「先跑起来，别为几分钱多一轮」。问价保护他的预算，也把便宜的决定拖慢；不问省下一轮，也让他可能在不知情下被扣。（词表键：决策成本——决定前把价与上限写清，还是先跑起来再说）|

## 连接与边界（你没说过的那一处）

**c-001　连接**：三条道是同一个动作的三个作用点：把系统需要的结构从他身上挪走——入口挪走「追问」（道二），事后挪走「检查」（道一），而决定处留下「价」（道三）。

为什么算新的：分开看，这三条像三个偏好；接起来才是同一句话，而仓里没有一句把它们接起来。　状态：`待确认`

**b-001　边界**：能挪走的只有「活」，不能是「形状」。　状态：`待确认`

他要的「活」是追问、检查、回访、维护；他要的「形状」是目的、边界、价和「什么时候停」。仓里现有的两句各说了一半：「零结构负担」（need.md 的 N1）只说别让他维护，「无声入库」（product.md）只说过程里别打扰；两句合起来容易被读成「什么都不给他看」。他的两句话把这条线画出来了：入口一眼要给全（道二），价要写在决定旁（道三），之后才轮到沉默与「可推翻」（道一）。

落到产品上的一句话：入口显式（目的、边界、价、停止点），过程沉默（不打断、不追问、不要求维护），事后可推翻（回执随问随答，没跑过就说没跑过）。

你一句话就能确认或推翻：**我把「活」拿走了，但入口那一眼的「样子」（目的、价、什么时候停）留给你——这句对吗？**

所有者：person；什么时候重开：他回来读这张图，或他一句话推翻；没有写进 product.md 与 need.md；本包不替他确认这一处，也不把它落成规则。
