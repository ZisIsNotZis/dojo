# 道图：13条道（p-dojo）

这几条道说的是同一件事：你要我把「活」拿走，但要先把「样子」和「价」摆在你面前。
其中有一条边界是我读出来的、你没说过；一句话就能推翻它，见「连接与边界」。

**这张图是一个人的。**记录里只有一位真人的具体经历，所以它证明的是这张库能把一个人的经历收成一张带边界的地图，
不证明它装得下第二个人的道理。目标仍是「人类的道」；要走到那儿，需要一个真实第二人的一场会话（`docs/probe/tension-convergence.md`）。

## 这张图里有什么

13 条道，每条六件套齐全；13 条都有自洽与可反驳两张回执，落地那一格 3 条有观察、10 条是「未跑」。
另有 9 条材料写不成道（按缺的那一件：情境 3、张力 4、动作 2、代价 2、失效 1、归属 1、重复 1），1 条候选，1 对互相打架；它们都在「没进库的东西」一节。
六件按来源合计：情境 系统补 13；张力 系统补 13；动作 他的原话 11、系统补 1、转述 1；代价 系统补 13；失效 他的原话 3、系统补 10；归属 他的原话 11、转述 2。
这一行是这张图最该被读的一句话：他给得出「做什么」和「从哪来」，给不出「什么处境」「哪两个好处在打架」「谁付什么」——那些是我补的，标着「系统补」。

**按作者分：他的 0 条、合写 13 条、系统的 0 条。**

**「合写」是一个状态，不是一句难听的话。**它说这条道的六件里有一些是系统补的：它只能被读成「他这样做的假设」，不能被读成「他的看法」。
规则是硬的：只要有一件是系统补的，这条道的词就不会是「自述」「验过」或「量过」——这三个词都在说「这是他的话」，而它有一半不是。
它的等级被最弱的那一件封顶；要升，只能等他一句新的确认或推翻，走「推断怎么变成他的」那条路。
独立来源 1 组（不同的人 1 个；曝光账本 0 行）。曝光未知按「不独立」算：这里是一个人的道理，不是共识。
提炼是这次会话的 manager 从记录里读出来的（凡读法处标「推断」），不是模型判定：这一包 0 次模型调用。

## 一条道长什么样

在 S 里，宁可 A 不 B，代价是 C；当出现 D 时，反过来。S 是适用域，A/B 是张力，C 是价格，D 是失效条件。
