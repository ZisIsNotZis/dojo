# 张力收敛探针：一页纸的做法、写法与判分规则

状态：**person 同意了做，root_manager 把它收窄到三个相熟者；本页是仪器和规则，还没跑，库里没有任何笔记。** 本页不招募、不定日期、不代约人；谁去做、什么时候做，是人的事。

## 0 这是谁的判断，为什么

person 的答复只有一句"ok"。
把五个陌生人换成三个相熟者，是 **root_manager 的推断，不是 person 的**。
理由：陌生人之所以值钱，是因为他们不共享语境；相熟者共享语境，所以他们的张力集合会**高估**重合。
因此这个收窄把结论的方向也改了一半：三个相熟者**不收敛**，已经足以说明"人类的道理可能不收敛"；三个相熟者**收敛**，只说明"值得去问陌生人"，不能读成"人类的道"。
下面第 4 节的判分规则就是按这两句话写成两段的。

## 1 一页纸：二十分钟怎么走

| 分钟 | 这一段做什么 | 开口第一句 |
|---|---|---|
| 0–2 | 开场：说清这是记录、逐字记、匿名成 p1/p2/p3、随时可以停 | 「我想听你讲两件你实际做过很多次的事，不评价，只记。」 |
| 2–8 | 第一件具体事：从"最近一次"开始，把细节问出来（几点、谁在场、你做了什么、结果） | 「最近一次是什么时候？那天从哪一步开始？」 |
| 8–14 | 第二件同类事：用来分辨这是模式还是偶发 | 「还有一次吗？那次有什么不一样？」 |
| 14–18 | 边界与代价：什么时候不该这么做、有没有反过来做也对的一次、那次牺牲了什么 | 「有没有一次你反着做，结果也对？」 |
| 18–20 | 复述校准：把"两件好事在打架"说出来，问是不是这两件 | 「我听到的是：要么……要么……，是这两件吗？」 |

**记录规则**（五条，缺一条这份笔记就没法跟别人比）：

- **逐字**，不概括、不改语气词、不替他补主语；他说的方言照写。
- 听不清写 `[不清]`，不猜。
- 提问写 `问：`，回答照写；每五分钟打一个时间戳 `[05:00]`。
- 人名、公司名、地名换成 `[某人]`、`[某公司]`、`[某地]`；不录其他可识别信息。
- 不录音，除非他也同意；纸笔就够。

**他开始讲道理而不是讲事的时候**（信号：「我觉得人应该……」「本质上……」「一般来说……」），按顺序用下面三个动作，一次只用一句：

1. 「举个最近的例子。」
2. 「那次你具体做了什么？」
3. 「当时你放弃了什么？」

两次都不落地（他还在讲原则），就让他讲完，把这一段标成 `[理论]`，**不计入张力**，除非后面出现了具体事件。
理由是硬的：张力必须有至少一个具体事件做锚，否则它只是措辞，而跨人比较措辞比的是词，不是道理。

**第 18–20 分钟的复述不是要他确认。** 他是被访者，不是校对员；复述是为了当场抓住你听错的地方，他纠正就记纠正，他不纠正也不构成背书。

## 2 张力怎么写（两个人能放在一起比）

一条张力一行，五格：

```
- [p1-T1] 省力 ↔ 练习 | 情境: 靠重复行为维持一个状态，动机不足以单独支撑 | 方向: 降摩擦 | 原话: "一想到要收就很烦" | 锚: 03:10
```

- **A ↔ B**：两个**不能同时拿满的好东西**，各写成不超过六个字的名词短语。写不成名词短语的，说明它还是抱怨或结论，不是张力。
- **情境**：一句话，能让没在场的人认出"什么人在什么阶段受什么约束"。
- **方向**：这个人往哪边偏（降摩擦 / 先澄清 / 宁可慢）。**方向不参与比较**：两个人偏相反也算同一条张力，而且这比"两个人说法一致"更值钱——一致的两个人可能是一个人学了另一个人，偏相反的两个人不可能。
- **原话**：逐字一句，不改。
- **锚**：那件事在第几分钟。**没有锚的行不计入重合**，只在报告里计一个"无锚"数。

**两个人算不算同一条张力**，三个问题，三个都"是"才算：

1. 两个好东西是同一对（允许同义，比如 省力 = 摩擦、坚持 = 练习；同义只认 `merges.md` 里登记过的，不认"我觉得像"）。
2. 把其中一个人往反方向摆，另一个人会说"对，就是那个两难"。
3. 一个没参加访谈的人读完这两行，能说出"这两个人卡在同一处"。

**什么时候算不同的张力**：好东西不是同一对；或者同一对词被用在两个不同的两难上（"快 vs 好"在发货和在做饭不是一回事，除非第 3 问判同）。
**拿不准就记成两条**，行尾加 `?`。这里的风险是把重合算高，不是算低；`?` 的两条只在有人按第 3 问判过之后才合并，合并写进 `merges.md`，并写明谁判的、为什么。
这把尺就是设计里"同一条道"的替换试验在张力这一层的用法：**同一对好东西、同一处卡住 = 同一条；否则不是。**

## 3 笔记放哪、什么格式、一条命令

- 一场一个文件：`docs/probe/notes/p1.md`、`p2.md`、`p3.md`，从 `_template.md` 复制。
- 文件头四行必须写：`person:`、`date:`、`minutes:`、`sample:`（`acquaintances` 或 `strangers`）。
- 正文两节：`## 逐字`（照第 1 节记）和 `## 张力`（照第 2 节写）。
- 合并登记：`docs/probe/notes/merges.md`，一行一条 `A ↔ B = C ↔ D`，后面写谁判的、为什么。
- **一条命令**（不调模型，纯本地计算）：

```sh
python3 scripts/tension_overlap.py docs/probe/notes
```

它打印：每人的张力条数（含无锚数）、两两交集与 Jaccard、所有场次共有的条数（三场时就是三个人共有）、两两 Jaccard 的中位数，以及按第 4 节规则得到的结论。
没有笔记时它只打印"没有笔记（0 场）"，不给结论——空集不能读成任何一种结果。

## 4 判分规则（数据到之前写死，之后不许改）

两个指标：`core` = 三个人都有的张力条数；`m` = 两两 Jaccard 的中位数。

| 结果 | 条件 |
|---|---|
| **收敛** | `core ≥ 3` 且 `m ≥ 0.30` |
| **不收敛** | `core ≤ 1` 或 `m < 0.10` |
| **说不准** | 其余（`core = 2`，或 `0.10 ≤ m < 0.30`） |

两段结构，按样本类型决定哪个结果算数：

- **样本是相熟者**：只有"不收敛"是结论。"收敛"与"说不准"都只写成"值得去问陌生人"，不能写成"人类的道"。
- **样本是陌生人**（如果之后扩到三个陌生人）：三种结论都成立，此时才能说这个库的故事是"人类的道"。

为什么是这三个数：三个人各出 4–7 条时，`core = 3` 意味着至少一半的核心重合；`m = 0.30` 与它大致同量级；`m < 0.10` 意味着两两几乎不共享。
它们是**判断**，不是测量，所以写在看数据之前，免得事后挑一个好看的门槛。

这个规则解释不了的情形，写"访谈不足"，不写"不收敛"：三人里有任何一人只出 1–2 条张力，或有一场全是 `[理论]` 没有锚。
访谈不足不是结果，是没做成；重做一场，不拿它凑数。

## 5 这一页不做什么

- 不调模型、不自动提炼、不做语义合并（合并只认 `merges.md` 里人写的那几行）。
- 不招募、不定日期、不代替任何人约人。
- 不把结论写成"证明了什么"：它最多说明这个库的故事该往哪边讲，说的是"值不值得继续"，不是"对不对"。
- 不因为结果不好看而改规则；规则改了就是新的一次探针，旧的结论作废并写明。
